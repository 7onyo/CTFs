# Non Fungible Token

All my friends got NFTs and joined an exclusive yacht club. Can you mint a boring NFT for me as well, please?

> **Attention!**
> 
> This is not a standard CTF challenge. Your objective here is to create an EDSAC program that will showcase your initials on the long tank (the main memory tank). 
> 
> * **Example:** If your name is Rachiteanu Sergiu, your program should display the letters 'R' and 'S'. 
> * **Visual Reference:** [EDSAC Memory Tank Example](https://github.com/Fineas/EDSAC-playground/blob/master/img/memory.png)
> 
> **Submission Guidelines:**
> 1. Once you have successfully written and tested your program on your local emulator, share **only the program's source**.
> 2. This is essential for the author to verify your solution. 
> 3. If your solution is correct, you will receive the flag as a comment.
