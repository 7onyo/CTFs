# EAXY Challenge

## Description
This challenge is so EAXy.

> Note: this is a static challenge. This means that there is no remote service. Your objective is to identify the correct value of EAX at the end of the program. You should submit it in hexadecimal form in this format UVTCA{number}. This means that if EAX contains the value 10, you will submit the flag as following: UVTCA{0xa}.
